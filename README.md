Source for Suzhe Xu's academic homepage. Deployed via GitHub Pages.

The page template is adapted from Jon Barron's homepage (https://jonbarron.info/).

The default homepage is English (`index.html`); the Chinese version is
`zh.html`. Both pages share `stylesheet.css` and link to each other using the
language switch. Keep research descriptions, dates, publication status, and
links consistent when updating either page. There is no automatic language
redirect or stored language preference.
